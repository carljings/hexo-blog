折腾 Claude Code 之后，我留下了这套日常配置

这次配置 Claude Code，我在网络上花的时间最多。网页能打开，终端未必走同一条线路；Mac 配好了，VPS 上的请求又是另一回事。我把现在的配置和使用步骤记下来，方便以后自己查，也给有类似需求的人参考。

注册邮箱：长期在用的 Gmail 优先

如果已经有用了多年的 Gmail，而且一直能正常收信，我会直接用它注册 Claude，不必再折腾一个新邮箱。找验证码、翻登录邮件和恢复账号都更方便。没有合适的邮箱，再去 Proton 申请一个免费账号，按页面完成验证。

接着打开 claude.ai，用自己的邮箱注册／登录，完成页面要求的验证。Claude 当前的官方说明要求新用户验证支持地区手机号，并实际位于支持地区。换邮箱或改用海外线路，不会改变这些条件。

Claude Code 沿用 Claude 账号，无须单独注册。个人 Pro／Max 套餐包含 Code 访问，免费网页版账号则不等于已经有订阅版 Code 权益；也可以选择另行计费的 Console 认证。具体见官方套餐说明。

我的网络怎么走

点击图片查看高清。图中隐藏了真实 IP 和凭据；VPS 本机的出口、登录情况需要单独检查。

我现在把 Mac 和手机常用的出口固定在“38”线路，前面接泡泡Dog或 TaiShan 节点。两台设备的用法有些区别：

  • Mac 用分流。 Clash 开启 TUN，GFWList、GFW geosite 和之前添加的 255 项域名走固定组，国内与内网按原规则直连。GFWList 用的是核对过的快照，暂时没有自动更新。
  • iPhone 用全局。 Clash Mi 里确认 GLOBAL → 出口-38芝加哥 → Static-38…。进入 VPN 的国内流量也会走 38，不用再塞一份 GFWList。
  • GreenCloud 单独看。 我还有一台 GreenCloud VPS，可以提供备用的“64”代理出口，也可以在上面直接运行 Claude Code。当前 Mac 的 38 链路不经过这台 VPS。换出口前，要一起检查 Switcher 的锁定配置。

这条 38 线路不支持 UDP，相关流量已禁用或拒绝，通话、游戏等功能可能受影响。不同数据库对它的地区判断也不一致，我更看重实际连接记录。手机换 Wi-Fi、切蜂窝网络后，都要重新看一次出口、DNS 和 IPv6。

Switcher 平时怎么用

我基于 YOURSJEYO/claude-switcher 做了一些调整，代码放在个人定制分支 custom/strict-macos。主要是把每次手动检查网络、切桌面账号这些事集中到一个窗口里。

示例界面，版本 20261025.2；IP 和邮箱均为演示数据。

  1. 打开软件，等检查完成。红色项先处理，黄色项点开看具体原因，灰色项是说明。改过网络后，点“重新扫描”。
  2. 要用桌面账号，先选 A／B，再点“确认打开账号 X”。软件会重新检查，然后切换并打开 Claude。
  3. 要用网页，点“专用浏览器打开 cc web”。这个浏览器有自己的登录状态，不跟着桌面的 A／B 切换。
  4. 要确认 CLI 用的是谁，在运行 Code 的那台机器上执行 claude auth status --text。不要只看 Switcher 里的邮箱标签。

我的版本还检查 Chicago 时区、en-US 地区格式和英文首选。这是我给本机定的要求，不能据此推断官方会不会封号。窗口显示“本地通过”，说明本地检查通过，不代表官方账号审核结果。

注册后的一周，我会怎么用

我会给自己留一周左右，先看看收信、登录和网络有没有问题，再决定长期订阅。这段时间正常做自己的任务就行，不需要每天凑聊天次数。

第一天把官方验证做完，确认邮箱能收信、浏览器能登录，出口也与配置一致。接下来几天正常使用，碰到断线、限额或额外验证就记录下来；改了配置，再检查一次。还没开通 Code 权益时，可以先用 Claude 网页版熟悉功能。

一周后再看自己是否需要付费。急着用 Code，也可以按官方条件直接订阅，不用硬等满七天。“观察一周”是我的安排，没有官方证据证明这样就能降低封号概率。

如果已经出现 on hold 或停用提示，就用原账号走官方复核／申诉。等待几天、反复换邮箱或自动刷聊天，都不能代替这个流程。

长时间开发，我更倾向用 GreenCloud VPS

项目和开发环境留在 VPS 上，配合 SSH、tmux，本地窗口断开后也容易接着干活。这是我想把长任务放到 GreenCloud 的主要原因。

先在 VPS 上按官方快速开始安装 Claude Code，并准备好 tmux。下面的主机别名和项目目录换成自己的：

ssh my-vps
tmux new -As claude-work
cd ~/my-project
claude

首次运行时按提示登录。如果 SSH 环境没有自动打开浏览器，可以按 c 复制登录链接，在本地浏览器完成授权。页面和终端提示需要授权码时，再填回终端。另开一个 SSH shell，或者退出 Claude 交互会话后，检查登录身份：

claude auth status --text

在 VPS 上运行，模型请求就由 VPS 发出。它的路由、IPv4／IPv6 和登录账号要另外检查，Mac 上的 Switcher 管不到远端。后续把这条链路验好，再作为日常开发环境。

登录细节见官方认证说明，代理设置见网络配置文档。

iPhone 上用礼品卡订阅 Plus 和 Pro

先确认自己符合服务的地区与账号要求。礼品卡要和 Apple 商店地区一致：例如使用合规可用的美区 Apple Account，就选美国区 Apple Gift Card。

  1. 从 Apple 官方或授权渠道购卡。先看会员结算价、税费和现有余额，再决定买多少；旧式硬件购物卡不能当作 App Store 充值卡。
  2. 打开 App Store → 头像 → 兑换充值卡或代码，把金额充进 Apple Account 余额。
  3. 打开对应的官方 App，确认登录的是准备长期使用的账号，再购买会员。
会员 官方 App 购买入口
ChatGPT Plus ChatGPT，开发者 OpenAI OpCo, LLC App 内选择升级 Plus，核对 Apple 购买确认页。
Claude Pro Claude by Anthropic，开发者 Anthropic PBC App 设置中选择升级 Pro，核对 Apple 购买确认页。
  1. 购买后回到原来的 ChatGPT／Claude 账号，确认会员权益。续费和取消在 iPhone 设置 → Apple Account → 订阅中管理。如果网页端已经订阅，先核对，避免买两份。

金额以手机结算页为准，余额支付有时仍会要求备用付款方式。Apple 账号负责付款，ChatGPT／Claude 账号承接会员，买之前一定看清登录的是谁。Plus 和 Pro 也不包含各自 API 平台的按量费用；使用 Code 时，留意 API Key 是否改变了计费方式。

Apple 礼品卡说明 · 余额用途 · ChatGPT iOS 订阅 · Claude iOS 订阅

付款失败，先看卡在哪一步

我会先到“设置 → 姓名 → 媒体与购买项目 → 查看账户 → 购买记录”查订单，再看订阅状态，确认订单是没生成、待处理，还是已经完成。这里说的是 Apple 内购；如果 App 跳转到网页付款，就要按网页账单处理。没弄清之前，先别重复购买。

遇到的情况 先怎么处理
礼品卡兑换失败 核对卡种、发行地区和账号商店地区。未激活先找售卡商，代码损坏或仍有问题再找 Apple，保留购卡凭证。
余额有钱，仍提示无法购买 检查金额是否够付税费、是否有未付订单，以及页面是否要求备用付款方式。出现“上次购买存在账单问题／需要验证”，先到购买记录处理欠款。
Apple 订单已完成，App 仍是免费版 核对购买时的服务账号。ChatGPT 可在“设置 → Account → Restore purchases”恢复购买；Claude 先核对原登录邮箱，仍未到账就带订单号联系 Claude 支持。
重复扣款或想申请退款 Apple 内购到 reportaproblem.apple.com提交申请；待处理订单通常要等收据生成。是否批准由 Apple 判断，取消续费和退款要分别处理。

礼品卡兑换问题 · 欠款处理 · ChatGPT 恢复购买

如果看到 Purchase Not Completed，并且弹窗有 Continue，就按提示提交购买复核。Apple 官方说明写得很明确：客服不能替你提交，也不能加速审核。遇到银行卡被拒，则还可能需要联系发卡银行。

在线客服怎么联系

Apple 付款、礼品卡或欠款问题：打开 Apple 支持，进入“账单与订阅”或 App Store 相关问题，登录自己的 Apple Account，按页面选择聊天、电话或回电。也可以用 Apple Support App；聊天是否开放，以对应地区和时段的页面为准。

ChatGPT 会员没到账：先登录购买时的 ChatGPT 账号，再打开 OpenAI 帮助中心，点右下角消息气泡，说明是 iOS 订阅问题。先由虚拟助手接待，需要时再跟进人工支持。附上服务账号邮箱、Apple 订单号、报错和恢复购买的结果，别在另一个账号上再买一次。官方联系客服说明

Claude 会员没到账：登录 Claude，点头像／姓名 → Get help → Send us a message → Accept，选择相关问题；也可从帮助中心右下角发消息。先由 Fin 接待，需要调查时再跟进，回复会留在会话里并发到账号邮箱。它是异步支持，免费账号主要使用 Fin 自助，不保证即时人工。官方客服说明

给客服的第一条消息可以这样写，把方括号换成实际情况：

我在 iPhone 为［ChatGPT Plus／Claude Pro］购买订阅，提示［完整报错］。发生时间是［时间和时区］，Apple 商店地区为［地区］，金额为［金额和币种］，订单状态是［未生成／待处理／已完成］。我已做过［检查余额／处理欠款／恢复购买］，请帮我确认下一步。我可以提供购买凭证或订单号。

Apple 内购的退款由 Apple 处理，OpenAI 和 Claude 客服主要帮你核对各自的账号与会员问题。礼品卡序列号、购卡凭证等材料，只在自己打开的官方支持渠道按要求提交；不要发送密码、验证码或完整银行卡信息。Cookie、Token 和完整代理配置也别公开。
