加密算法学习

密码学家的工具箱（6 件套）

  • 1、对称加密
  • 2、公钥加密（非对称加密）
  • 3、单向散列函数
  • 4、消息认证码（一种与共享密钥有关的单向散列函数，确认消息是来自正确的发送者和完整性，完整性和认证，但无法防止否认）
  • 5、数字签名（将公钥加密反过来用，作用和消息认证码一样，无法否认，但公钥需要认证）
  • 6、伪随机数 生成器（不存在统计学偏差随机性，不能从过去的数列推测出下一个出现的数不可预测性，不能重现相同的随机数不可重现性）

密钥：秘密的精华，与明文等价，使用随机数生成，加密算法和秘钥分离，不要尝试使用未公开的加密算法

一、散列算法 hash

MD5 128bit 杂凑 安全中 速度快
SHA-1 160bit 杂凑 安全较高 速度较慢
SHA-2 (包含 SHA-224、SHA-256、SHA-384、SHA-512、SHA-512/224、SHA-512/256) 安全高 速度慢
SM3 256bit 杂凑 安全高 速度慢（推荐）

二、对称加密算法

DES（不安全，几小时内就能暴力破解，Feistel 网络）
3DES（小规模使用，目前暂且允许使用，不推荐使用、Feistel 网络）
AES（取代 DES，推荐使用，Rijndael 被 NIST 选定为 AES 标准，SPN 结构，subbytes->ShiftRows->MixColumns->AddRoundKey）
SM4（推荐，和 AES 媲美，仅广泛使用在中国国内，比 SM1 有更好的性能）
SM1（主要用在一些加密硬件设备，比如银行卡和密码设备，用在金融行业，设计细节未公开）

三、非对称加密算法

RSA（推荐，使用最广，利用质因数分解难度来抵抗破解）
ECC(效率更高，占用资源更少，兼容性低一些)
SM2（推荐，基于 ECC，优缺点同等 ECC，兼容性最低，没有被国际上广泛使用）
使用普遍度 RSA>ECC>SM2

四、数字签名：

内容 ->Hash 算法 -> 摘要 -> 私钥加密 -> 数字签名
数字签名 -> 公钥解密 -> 摘要

公钥加密，私钥解密
私钥签名，公钥验签
PKI 体系（公钥基础设施）

五、数字证书：

解决公钥造假问题，公钥认证 （给公钥加上数字签名）
公钥等用户相关信息 ->CA 私钥加密 -> 数字证书
内容 + 数字证书 + 数字签名 ->CA 公钥解开数字证书 -> 拿到公钥 -> 解密数字签名 -> 摘要

六、消息认证码

消息 -> 消息验证码算法 + 共享密钥 ->MAC 值（消息验证码）
